# Design System & Tokens (Vitababy)

Este documento centraliza as definições de interface extraídas do Figma base.

## 🎨 Cores (Paleta Principal)
- **Primary / Brand:** `#AE4D30` (Laranja avermelhado / Terracota) - Usado em botões principais e destaques.
- **Background Principal:** `#FBF9F5` (Off-white / Bege claro) - Usado no fundo geral da página.
- **Background Secundário:** `#F5F3EF` (Bege um tom mais escuro) - Usado para separar seções (ex: Seção de Serviços).
- **Textos Principais (Heading):** `#411F03` (Marrom escuro) - Usado nos títulos.
- **Textos Secundários (Body):** `#444840` (Cinza chumbo/esverdeado) - Usado em parágrafos e subtítulos.
- **Destaque Secundário / Badge:** `#D19A7E` (Terracota claro) - Usado em crachás, textos menores e links secundários.

## 🔤 Tipografia
- **Títulos (Headings):** `Libre Caslon Text` (Serif)
- **Textos (Body / UI):** `Hanken Grotesk` (Sans-Serif)

## 📦 Componentes Base
Os componentes serão construídos em cima do **Shadcn UI** mantendo a acessibilidade (Radix UI) e a customização via TailwindCSS usando os tokens acima.
